# Contributing

Thank you for contributing to Creignificent AI Agents.

1. Keep changes scoped to a clear objective.
2. Never include secrets, customer information, or proprietary data.
3. Add or update tests for behavioral changes.
4. Update documentation when behavior or configuration changes.
5. Preserve human-approval and security boundaries.

Pull requests should explain what changed, why, how it was tested, security implications, and any new environment variables or external services.

Contributions are made under this repository's license.
