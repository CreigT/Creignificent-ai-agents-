# Foundation Usage

1. Choose an entry from AGENTS.md.
2. Create a dedicated repository for that agent.
3. Copy the standard governance and security files from this foundation.
4. Start its README from templates/AGENT-README-TEMPLATE.md.
5. Implement only the capability claimed by its maturity status.
6. Run the open-source release checklist.
7. Review dependency and asset licensing.
8. Publish only after secret/security review.
9. Tag a release when the project has a reproducible version.

This foundation is a catalog and standard, not proof that every listed agent is already implemented.
